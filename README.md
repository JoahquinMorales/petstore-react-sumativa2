## Tecnologías Utilizadas
* **React (JavaScript):** Construcción de interfaces mediante componentes reutilizables (SPA).
* **Bootstrap:** Estilos y sistema de grillas para garantizar una responsividad fluida (mobile-first).
* **Karma & Jasmine:** Entorno de pruebas unitarias automatizadas para asegurar la calidad del código.
* **Node.js (LTS):** Entorno de ejecución para la gestión de dependencias y servidor local.

## Guía de Instalación y Ejecución Local

Sigue estos pasos para clonar y ejecutar el proyecto en tu máquina de desarrollo:

### 1. Clonar el repositorio
```bash
git clone <url-del-repositorio>
cd petstore-react-sumativa2-main
```

### 2. Instalar las dependencias
Asegúrate de tener Node.js instalado (versión LTS recomendada). Luego, en la terminal ubicada en la raíz del proyecto, ejecuta:
```bash
npm install
```

### 3. Ejecutar la aplicación
Para iniciar el servidor de desarrollo local, ejecuta:
```bash
npm start
```
La aplicación se abrirá automáticamente en tu navegador predeterminado en la dirección `http://localhost:3000` (o el puerto disponible).

---

## Ejecución de Pruebas Unitarias
Para correr la suite de pruebas unitarias configuradas con Karma y Jasmine, utiliza el siguiente comando en la terminal:
```bash
npm test
```
